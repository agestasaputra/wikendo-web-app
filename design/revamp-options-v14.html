Bottom navigation 20 opsi — BN1 s/d BN20

Masalah: Wikendo belum punya navigasi bawah ala mobile app — user pindah Home / quiz tempat / quiz makan / mall / akun cuma via header + CTA. Solusi P0: sticky bottom-nav max-w-md, thumb-zone min 56px, ikut token live (paper/ink/lime/ember/rose), hormati split tempat vs makan (tidak dicampur), hormati header 2-state AS6. Mock di bawah = Home live + nav varian.

Kenapa bottom-nav penting (3 kalimat)

  • Jempol tidak sampai header: 80% tap HP di zona bawah — pindah quiz/mall dari nav bawah menaikkan landing-ke-quiz.
  • Split tetap jelas: Tempat dan Makan dua tab eksplisit — tidak dicampur, tidak disembunyikan di balik satu FAB ambigu.
  • Akun konsisten header: nav Akun cerminan header AS6 (anon = Login, login = avatar) — tidak bikin pintu ganda.
